# Nhat Tam • Personal Bio & Sanctuary

> Elite personal portfolio and bio website featuring realtime Discord presence, bespoke audio controller, dynamic particle effects, and sleek luxury monochrome aesthetic.

## ✨ Features
- **Realtime Discord Presence**: Powered by Lanyard Gateway (WebSocket & REST fallback) displaying live status, games, custom status, and Spotify activity.
- **Audio Sanctuary Controller**: Dual-track background audio with visualizer disc, track progression, and seamless autoplay overlay.
- **Bespoke Aesthetics**: Cyber-reticle cursor, dynamic particle canvas, 3D card tilt & glare reflections.
- **Responsive Bento Layout**: Mobile & desktop optimized layout with server communities and direct socials.
